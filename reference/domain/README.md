# Domain

Cross-cutting domain knowledge shared across Databús, Infobús, and all SIMOVI agents.

- [`naming.md`](naming.md) — Naming conventions for services, processes, states, events, actions, and messages in the Databús/Infobús ecosystem. Includes the `databus.` namespace rules and concrete examples.
- [`gtfs.md`](gtfs.md) — GTFS Schedule and GTFS-RT essentials: required files and fields, time/date format rules, stop_sequence semantics, FeedMessage protobuf structure, and incrementality modes.
- [`transit-concepts.md`](transit-concepts.md) — Vocabulary glossary for core transit domain terms: run, trip, route, stop, vehicle, telemetry, dispatcher, operator, and lifecycle distinctions.
