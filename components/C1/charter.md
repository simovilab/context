# Gestión de datos del transporte público (Public transport data management)

Establece la infraestructura institucional para la recopilación, estructuración, validación y publicación de los datos oficiales del servicio de transporte público mediante el estándar GTFS, consolidando la información de CTP, INCOFER y ARESEP en un conjunto de datos coherente, e institucionalizando el proceso de actualización y gobernanza de esos datos.
