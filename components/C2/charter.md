# Editor administrativo de datos GTFS (GTFS data administrative editor)

Establece la plataforma institucional para la creación, edición, validación y publicación de los datos oficiales del transporte público en formato GTFS Schedule, mediante una herramienta con interfaz gráfica, validación automática, flujos de aprobación institucional y registro histórico de cambios.
