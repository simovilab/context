# Sistema web de gestión de alertas operativas

Operational alerts management web system

Plataforma web institucional para la creación, validación y publicación de alertas operativas del servicio de transporte público, basada en GTFS Realtime Alerts y sujeta a reglas de publicación y permisos administrativos.
